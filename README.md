# Stock Portfolio Tracker

## CodeAlpha Python Programming Internship – Task 2

### Project Description

The Stock Portfolio Tracker is a Python-based application that helps users manage their stock investments. It allows users to buy and sell stocks, view their holdings, and calculate the total value of their portfolio.

### Features

* Display available stocks and their prices.
* Buy stocks and update portfolio holdings.
* Sell stocks and manage share quantities.
* View current stock holdings.
* Calculate total portfolio value.
* Save portfolio data in a JSON file.
* Automatically load previously saved portfolio data.
* Handle invalid user inputs.

### Technologies Used

* Python
* JSON
* File Handling

### How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python stock_portfolio.py
```

### Available Stock Prices

The project uses predefined sample stock prices in Indian Rupees (INR).

### Project Files

* `stock_portfolio.py` – Main Python program.
* `portfolio.json` – Stores saved portfolio information.
* `README.md` – Project documentation.

### Note

This is a beginner-level stock portfolio management project. The stock prices are sample values and are not connected to real-time stock market data.
